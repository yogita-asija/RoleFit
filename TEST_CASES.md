# Test cases

Five **fictional** resume / job-description pairs used to compare the three prompt versions. Generated from `backend/src/data/testCases.js` (`npm run docs:testcases`).

## TC1: Data Analyst Intern

**Resume**

```
Aanya Rao, BSc Statistics (Year 3), Fictional City University
Skills: Python, SQL, Excel, pandas
Projects:
- Built a sales dashboard in Tableau for a class project using a public retail dataset.
- Cleaned and analysed survey data with Python and pandas for a statistics course.
Experience:
- Student tutor: explained probability to 20 first-year students each week.
```

**Job description**

> Data Analyst Intern. Requirements: Python and SQL for data analysis; Tableau or Power BI dashboards; knowledge of statistics; experience with machine learning is a plus. Currently studying a quantitative degree.

**Expected skills demonstrated:** python, sql, tableau, statistics

**Expected gaps (must NOT be claimed as demonstrated):** power bi, machine learning
